# دخل‌وخرج من

نرم‌افزار شخصی مدیریت درآمد و هزینه — فارسی، آفلاین‌اول، با همگام‌سازی روی لپ‌تاپ شخصی.

**وضعیت:** مرحلهٔ ۲ از ۵ — رابط کاربری کامل و ذخیرهٔ دائمی روی دستگاه (IndexedDB). سرور، همگام‌سازی و پشتیبان‌گیری در مراحل بعد.

## اجرای پیش‌نمایش

نیازمند [Node.js](https://nodejs.org) نسخهٔ ۲۰ یا بالاتر.

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # تست‌های تاریخ شمسی، مبلغ و محاسبات
npm run build
npm run build:single -w client   # یک فایل HTML مستقل برای پیش‌نمایش
```

مشاهده روی آیفون (فقط برای دیدن ظاهر): لپ‌تاپ و آیفون روی یک Wi-Fi باشند و آدرس «Network» نمایش‌داده‌شده توسط `npm run dev` را در Safari باز کنید.
توجه: روی آدرس HTTP، قابلیت‌های PWA و آفلاین کار نمی‌کنند؛ این موضوع در مرحلهٔ ۳ با HTTPS محلی حل می‌شود.
