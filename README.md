# دخل‌وخرج من

نرم‌افزار شخصی مدیریت درآمد و هزینه — فارسی، آفلاین‌اول، با همگام‌سازی روی لپ‌تاپ شخصی.

**وضعیت:** هر پنج مرحله پیاده‌سازی شده‌اند (نسخهٔ ۰٫۵٫۰): رابط کاربری، ذخیرهٔ آفلاین، سرور لپ‌تاپ، همگام‌سازی، پشتیبان/بازیابی، CSV و PWA. آزمایش روی ویندوز و آیفون واقعی هنوز انجام نشده است.

**راه‌اندازی روی ویندوز و آیفون:** [docs/SETUP-WINDOWS.md](docs/SETUP-WINDOWS.md)

## اجرای پیش‌نمایش

نیازمند [Node.js](https://nodejs.org) نسخهٔ ۲۰ یا بالاتر.

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # تست‌های برنامه و سرور
npm run server     # اجرای سرور (پس از npm run build)
npm run build
npm run build:single -w client   # یک فایل HTML مستقل برای پیش‌نمایش
```

مشاهده روی آیفون (فقط برای دیدن ظاهر): لپ‌تاپ و آیفون روی یک Wi-Fi باشند و آدرس «Network» نمایش‌داده‌شده توسط `npm run dev` را در Safari باز کنید.
توجه: روی آدرس HTTP، قابلیت‌های PWA و آفلاین کار نمی‌کنند؛ این موضوع در مرحلهٔ ۳ با HTTPS محلی حل می‌شود.

جزئیات معماری: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
